# Roadmap

IssuePilot is intentionally starting with a small, understandable core.

## 0.1

- GitHub issue ingestion
- deterministic triage
- optional Claude provider
- duplicate candidates
- dry-run reporting
- opt-in comments and labels
- CI workflow

## Next

- configurable repository label mapping
- persistent triage state to avoid repeated comments
- GitHub webhook mode
- evaluation fixtures for classifier quality
- provider-independent structured-output validation
- metrics for triage accuracy and reviewer agreement

## Longer term

The project should remain useful as a conventional GitHub maintenance tool even as model providers change.
