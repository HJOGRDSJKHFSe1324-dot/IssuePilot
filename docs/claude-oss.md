# Claude for Open Source positioning

IssuePilot is an open-source GitHub maintenance tool. Its core value is practical repository maintenance: first-pass issue classification, duplicate discovery, summaries, and safe automation.

Anthropic's current Claude for Open Source program lists several eligibility paths, including maintainers of widely depended-on packages, core contributors to recognized projects, active contributors, community builders, and maintainers of critical infrastructure. The program also says people who do not exactly fit a listed criterion can still apply when they maintain software the ecosystem depends on.

This repository should therefore be represented accurately in any application. Do not claim download counts, dependent repositories, contributors, stars, or impact that the project has not actually earned.

A sensible application narrative for a young project focuses on:

- the concrete maintenance problem being solved
- why safe issue triage is useful to open-source maintainers
- how Claude is used as an optional provider rather than hidden vendor lock-in
- the project's safety defaults and transparent automation
- what the project plans to measure as adoption grows
